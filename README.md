# Relay3

## 面向使用用户

局域网文件互传与文字群聊工具。Windows / Mac 安装客户端，安卓 / iOS 手机扫码后使用浏览器，无需安装。桌面可同时作为中转站和客户端，运行时不依赖外网。

[下载安装包](https://github.com/nekomorph-woo/relay3/releases/latest) · 提供 Mac Apple Silicon 与 Windows x64。

**开始使用**：在桌面「本机中转站」开启服务 → 其他桌面选择附近中转站并输入配对码，手机扫描二维码 → 选择设备发送文件，或进入群聊大厅。

| 界面         | 可以做什么                                                                                                                                                                                                                   |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 文件传输     | 选择接收设备、添加或拖入文件，查看进度，接受、拒绝或取消传输。桌面接收自动保存并校验文件；手机完成下载后确认收到。                                                                                                           |
| 群聊大厅     | 发送与复制文字，查看永久保存的历史、未读消息和设备列表。普通消息直接展示；密文在发送端加密、授权设备本地解密，支持已登记密钥的离线设备和公开备注。Markdown / HTML 保持原文，不发送图片或文件。管理员可组合条件批量清理历史。 |
| 收发记录     | 查看文件名、大小、发送方、接收方、时间、耗时和中转站来源；支持搜索、筛选与手动清理，不自动删除。旧记录缺少来源时显示「其他」。                                                                                               |
| 连接的中转站 | 桌面同时连接多个站，查看状态、传输数量与未读消息，切换、断开或忘记配对。各站传输和聊天草稿独立，切换不中断后台传输，重启恢复保持连接的站。手机保持单站连接。                                                                 |
| 本机中转站   | 开启或关闭本机服务，查看站名、地址、二维码与 6 位一次性配对码；本机可直接加入。同一桌面只开启一个中转站。                                                                                                                    |
| 连接设备     | 管理本机中转站的在线、离线设备与连接时间线。按设备清除，或按最近连接时间批量清理离线历史；统一头像和平台图标帮助辨认设备。                                                                                                   |
| 接收文件     | 按中转站查看客户端下载的文件，复制保存路径、打开目录或手动删除；文件不会自动清理。                                                                                                                                           |
| 中转缓存     | 查看本机中转站暂存文件与磁盘占用，手动清理缓存、查看缓存目录及整理数据库；已完成缓存默认 1 小时清理。                                                                                                                        |
| 设备         | 修改设备名、站名、端口、缓存保留时间与保存位置；复制设备标识、更换身份，查看或导出本地异常诊断日志。                                                                                                                         |

设备需处于可互访的局域网，默认端口 **42830**；请允许防火墙连接，并让代理直连局域网地址。未发现附近中转站时，可使用地址或配对链接。文件通过中转站暂存后交付，适合可信局域网；公开备注所有设备可见，更换身份或丢失私钥后无法解密旧身份的密文。

覆盖升级保留原数据。安装包未配置商业签名或 Apple 公证。

## 面向开发者

**技术栈**：Electron + React + TypeScript + Vite；Fastify 提供 HTTP / WebSocket 服务，Node 内置 SQLite 持久化，bonjour-service 实现 mDNS 发现，electron-log 与 crashReporter 记录本地异常。聊天密文使用 X25519、HKDF-SHA256 与 AES-256-GCM。

**目录结构**：

| 目录               | 职责                                              |
| ------------------ | ------------------------------------------------- |
| `electron/`        | 桌面主进程、原生文件操作、局域网发现与诊断。      |
| `server/`          | 配对、设备管理、文件中转、群聊与 SQLite 存储。    |
| `src/`             | 桌面和手机共用的 React 界面、多站连接与端侧加密。 |
| `scripts/`         | 开发启动、预加载脚本与应用图标生成。              |
| `tests/`           | 服务测试及 Playwright Electron / 网页集成测试。   |
| `docs/`、`design/` | 设计说明、验证记录、发布说明与视觉资源。          |

**本地开发**（Node.js 24 或更新版本）：

```sh
npm ci
npm run dev
```

**构建与验证**：

```sh
npm run build                 # 类型检查及前后端生产构建
npm test                      # 服务、加密、发现与存储测试
npx playwright install chromium
npm run test:ui               # Electron 和手机网页集成测试
npm start                     # 启动已构建的桌面应用
npm run serve                 # 仅运行网页中转服务
```

开发和测试可通过 `RELAY3_DATA_DIR` 指定独立数据目录。测试覆盖传输完整性、配对权限、清理与持久化、多站隔离、重连、群聊、响应式和诊断；运行界面测试时需保证 Node 能直连本机调试 WebSocket。

**打包**：

```sh
npm run dist:mac              # Mac Apple Silicon DMG
npm run dist:win              # Windows x64 NSIS 安装程序
npm run pack                  # 本机应用目录
```

产物位于 `release/`，只包含编译资源和运行依赖。使用 ASAR、最大压缩及中文 / 英文语言资源；SQLite 无需额外原生插件。构建流程见 [.github/workflows/build.yml](.github/workflows/build.yml)。

**数据与接口**：

- Windows 数据目录：`%APPDATA%\relay3\`；Mac：`~/Library/Application Support/relay3/`。数据库为 `relay3.sqlite`，默认缓存为 `relay-cache/`，正式接收文件默认在系统下载目录的 `relay3/` 下。实际路径可在应用中查看。
- 多站会话以 `stationId` 区分，传输以站与传输 ID 共同隔离；来源名称保存快照，旧记录不回填。
- 控制服务只监听回环地址，管理接口使用独立凭证；开启中转站后才监听局域网。Electron 启用沙盒、上下文隔离、受限 IPC 与 CSP。
- 桌面聊天私钥位于数据目录 `chat-keys/`，手机私钥保存在对应站点的浏览器本地存储。日志和崩溃转储只保存在本地，不自动上传。
