# relay3

当前版本：0.3.1。安装包下载：[GitHub Release](https://github.com/nekomorph-woo/relay3/releases/tag/v0.3.1)，提供 Mac Apple Silicon 与 Windows x64。

PC、Mac、手机之间的局域网文件互传工具。桌面版支持 Windows 10 及更新版本、macOS 13 及更新版本。桌面端使用 Electron，手机通过浏览器连接，不需要安装客户端。所有前端资源随应用附带，运行时不依赖外网。

## 使用

1. 打开桌面应用，在「中转站」页开启中转站。
2. 本机点击「本机加入」；另一台桌面应用可粘贴配对链接连接。手机扫描二维码，在浏览器里输入设备名称后连接。
3. 在「文件传输」选择在线接收设备与文件，发送请求。接收方确认后，文件上传至中转站，再由接收方下载。
4. 桌面接收会校验大小与 SHA-256，完成后自动保存到接收目录；手机下载后需点击「确认收到」。浏览器不能可靠确认文件最终已保存至系统磁盘。
5. 在「文件存储」查看中转缓存、本机接收文件与数据库路径，打开目录或手动清理。

同一台 PC / Mac 可以同时开启本机中转站，并连接自己或另一台中转站作为客户端。手机只有客户端功能。关闭本机中转站不影响连接另一台中转站的客户端角色。

默认端口为 **42830**，可在关闭中转站后修改。设备需要处于可互访的局域网；首次启动需允许系统防火墙接受连接。访客 Wi-Fi 的隔离设置可能阻止设备互访。配对链接包含连接凭证，请通过二维码或可信渠道交给需要连接的设备。传输使用局域网 HTTP，适用于可信的家庭或办公局域网。

## 存储与清理

| 数据         | Windows                      | macOS                                   |
| ------------ | ---------------------------- | --------------------------------------- |
| 应用数据     | `%APPDATA%\relay3\`          | `~/Library/Application Support/relay3/` |
| 数据库       | 数据目录内的 `relay3.sqlite` | 同左                                    |
| 中转缓存     | 数据目录内的 `relay-cache/`  | 同左                                    |
| 本机接收文件 | 系统下载目录内的 `relay3/`   | 同左                                    |

- 数据库保存设备、连接时间线、传输历史、设置及本机接收文件信息；使用 WAL 日志保证持久性。
- 收发历史不会自动清理。桌面端保存自身经远端中转站的收发历史；本机中转站保存所有经它处理的历史。
- 中转缓存以唯一 ID 命名，`partial/` 存未完成上传，`ready/` 存完整文件。
- 仅「已完成」文件默认在确认接收后 **1 小时**自动清理。每 30 秒检查一次；应用关闭期间不会运行清理，重启后处理已到期缓存。待接收、失败或取消的文件需手动清理。
- 可修改保留时间，修改后的规则也应用于现有已完成缓存。
- 中转缓存位置可迁移到空目录；需先关闭中转站。迁移复制成功后再更新设置并移除旧目录。
- 本机正式接收文件不会自动清理；可以在应用里单独选择并永久删除。缓存清理不会删除正式文件。
- 「收发记录」支持手动清理已结束且本机缓存已删除的历史；「连接设备」支持清理没有待传输文件的离线设备历史。设备历史清理后需重新配对。
- 「整理空间」执行 SQLite checkpoint 和 VACUUM，仅回收空间，不删除记录。不要直接删除正在使用的 SQLite 或 WAL 文件。

## 开发与验证

需要 Node.js 24 或更新版本。

```sh
npm ci
npm run dev
```

```sh
npm run build
npm test
npx playwright install chromium
npm run test:ui
```

服务端测试覆盖配对权限、接收确认、流式上传、大文件完整性、拒绝和取消、手动与定时清理、缓存迁移、数据库整理和重启恢复。桌面集成测试直接启动 Electron，验证手机页面双向传输、正式文件落盘、清理后的历史、响应式布局、设备断开以及同时运行中转站与远端客户端。

macOS 服务测试使用系统 curl 直连回环地址，绕开系统代理对 Node HTTP 客户端的干扰。Playwright 还需要 Node 能直连本机调试 WebSocket；如果代理按进程接管 Node，请把它的 localhost 访问设为直连后运行集成测试。

只启动网页中转服务（仍使用同一份数据库实现）：

```sh
npm run serve
```

控制服务仅监听 `127.0.0.1` 的随机端口，中转站开启后才监听局域网。管理接口需要独立凭证，不向手机客户端开放。Electron 使用沙盒、上下文隔离、受限 IPC 与 CSP，禁用 Node 集成和额外窗口导航。

## 打包

```sh
npm run dist:mac       # macOS Apple Silicon DMG
npm run dist:mac:x64   # macOS Intel DMG
npm run dist:win       # Windows x64 安装程序，建议在 Windows 构建
npm run pack          # 本机未压缩应用目录
```

产物位于 `release/`。GitHub Actions 提供 macOS / Windows 原生构建与检查，当前没有配置远端仓库或发布。Windows 安装包使用支持 Apple Silicon 的 NSIS 3.12 工具集，跨平台打包不要求安装 Rosetta。

安装包只包含编译产物和运行依赖，分别打包 CPU 架构，使用 ASAR 与最大压缩，保留中文和英文语言资源。不附带额外 Node 运行时、外部字体、开发依赖或 source map。SQLite 使用 Electron 的 Node 内置模块，无需打包原生 SQLite 插件。

应用、Dock、安装程序均使用 relay3 专属图标。品牌原稿位于 `design/branding/`。

当前为未配置商业签名和公证的本地首版；正式分发可在构建环境配置 Apple / Windows 签名凭证。iOS / Android 实机后台与下载行为需依据系统浏览器验证，浏览器离开前台后可能暂停传输。
