# 六项界面反馈修复

- 设备搜索输入框移除来自通用标签规则的顶部外边距，与同排下拉框保持44px高度、顶部对齐。检查了历史筛选、设置、清理和配对表单。
- 中转站连接状态与设备状态归入信息区域；缓存和接收文件状态随文件名展示，旧传输状态独占一行，操作按钮分开。
- 文件输入框 cancel 事件不再触发父 dialog 关闭；文件发送弹窗仅右上角 X 关闭，取消选择保留文件和设备选择。
- 侧栏顶部上移16px，导航字号13→14px，分组标题10→11px；后台入口位于底部分隔线之上，小窗口导航继续独立滚动。
- 已结束任务（成功或失败）按结束时间保留5分钟；运行任务不会按时间消失。移除旧的20条结束任务数量上限。只清理内存浮窗列表，保留持久传输记录。
- 运行时显示旋转图标及“后台任务(N)”，空闲显示 Lucide list-todo；任务缺少设备名时不展示多余分隔点。
