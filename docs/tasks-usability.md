# 八项使用体验需求追踪

意图：在现有紧凑桌面界面中增加功能、改善流程，保留现有视觉和导航。
目标：用户能判断连接失败原因、及时处理多站任务，并可靠发送大文件与文件夹、找回历史。

## 范围与边界

- 不自动清除凭证、不用诊断消费一次性配对码；区分事实与推测。
- 密文正文与密文文件名不进入服务端明文搜索。公开备注可以搜索。
- 文件夹生成普通 ZIP，内部路径及内容不加密，外部文件名沿用现有密文方案。
- 保持现有接收截止 D 与缓存清理 T；重新投递生成新任务。
- 不改版本、不打 tag、不发布 Release。
