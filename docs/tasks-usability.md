# 八项使用体验需求追踪

意图：在现有紧凑桌面界面中增加功能、改善流程，保留现有视觉和导航。
目标：用户能判断连接失败原因、及时处理多站任务，并可靠发送大文件与文件夹、找回历史。

## 范围与边界

- 不自动清除凭证、不用诊断消费一次性配对码；区分事实与推测。
- 密文正文与密文文件名不进入服务端明文搜索。公开备注可以搜索。
- 文件夹生成普通 ZIP，内部路径及内容不加密，外部文件名沿用现有密文方案。
- 保持现有接收截止 D 与缓存清理 T；重新投递生成新任务。
- 不改版本、不打 tag、不发布 Release。

- [x] 5. 托盘/菜单栏后台运行、防自动休眠、退出与唤醒恢复

- [x] 7. SQLite历史搜索、筛选、分页与权限边界
- [x] 8. 临近截止提醒与新记录重新发送
- [ ] 集成验收：服务测试、UI测试、桌面体验与回归

## 阶段二证据与取舍

- 完整服务测试57项通过；已有UI回归37项通过。
- 新增跨端验收通过：真实文件夹ZIP生成、手机接收及中文目录内容验证、中文历史搜索与跳转、关闭窗口保持中转站服务、重新发送不改旧任务。
- 十万条中文消息索引完成后搜索「文件传」耗时13ms，返回30条及下一页游标（本机一次实测，非各平台保证）。
- 已完成准备任务仅在后台浮窗保留5分钟；主区只展示运行任务。实际截图自检，未独立评审。
- 文件夹最多十万个条目；符号链接与不可读项目需明确确认排除，接收端不自动解压。临时ZIP有效期24小时，上传投递成功后删除，退出删除临时压缩文件，原目录不受影响。
- 全站通知初连不弹历史，按站和事件去重、支持静音；手机仍为应用内提示。
- SQLite搜索3字符以上用trigram，1/2字符限最近一万条；端侧密文正文/文件名不索引。历史索引分批构建，查询在只读Worker进行。
- 默认关闭窗口直接退出；托盘模式需主动开启。传输防自动休眠默认开启，不保证合盖或手动休眠。
- ZIP64和流式机制已有内容测试，尚未用大于4GiB的实际文件验证；Windows与真实iOS设备仍需用户实机验收。
