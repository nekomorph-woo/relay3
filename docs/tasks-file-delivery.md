# 文件投递与群聊文件任务

Goal：统一普通/群聊文件投递，支持离线多目标、期限、重新下载及服务端可视任务，完成验收。

## 任务
- [ ] T1 共享文件与独立接收任务，旧记录兼容；离线多目标普通投递
- [ ] T2 上传即开始；D/T 持久化；首次接收超时、重新下载、重启/清理与并发保护
- [ ] T3 群聊文件消息、文件名端侧加密、接收/拒绝/下载联动、公开备注
- [ ] T4 桌面文件定位、本地存在性与最近成功下载记录；手机边界
- [ ] T5 服务端后台任务列表、上传/下载/检查/清理、动态入口与浮窗
- [ ] T6 Emoji Mart 与本地 Twemoji、跨端选择/展示、原文复制
- [ ] T7 中转站切换控件、输入留白、共享状态图标与 Tooltip
- [ ] T8 服务测试、界面测试、桌面/窄屏验收，打开新版体验

## 规则
- 发送后直接上传，只有完整上传才开始接收计时；一文件仅一份缓存。
- D=完整上传时间+10分钟至24小时接收缓冲；T=D+上传时中转站保留时长快照。
- 首次接收必须早于D；已成功接收可以在T前重新下载；不延长T。
- 下载中不因D/T到期中断；停止新下载，进行中下载结束再清理。
- 历史永久保留，缓存清理和历史清理分开。
- 普通文件可选择已登记离线设备；群聊还要求有效公钥，发送者仅参与解密。
- 中转站关闭不取消已上传任务；重启检查缓存和过期任务；不支持断点续传。
- 客户端本地文件缺失只影响本地可用状态，不覆盖历史接收结果。
- 手机浏览器不能检查下载目录，下载完成依赖用户确认。
