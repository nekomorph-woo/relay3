本次属于交互布局整理，沿用现有品牌、字体、颜色、业务功能与原生平台滚动条；不模拟滚轮惯性，不强制隐藏滚动条。

## 验收标准

- 每个内容面板拥有明确主滚动区，标题、筛选与主操作不会被长列表带走。
- 同向滚动不逐层传递；文本编辑框和设备选择下拉作为独立控件保留滚动。
- 切换站点与页面保留各自位置，切换筛选／分页重置到对应内容起点。
- 阅读历史时新消息不抢位置；回到最新继续跟随；历史翻页保持可理解的位置。
- 内容为空时布局不撑出多余滚动；窄屏不裁切内容和按钮。
- Mac／Windows 使用平台默认滚动条，不新增自绘滑块或滚轮事件接管。
