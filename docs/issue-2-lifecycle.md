# Issue 2：本机状态与连接生命周期

## 行为

- 侧栏「中转站服务端管理」旁展示本机状态：开启为绿色实心点，关闭为灰色空心点，另有文字与开关过程状态。点击进入本机中转站页。
- 正常退出与 SIGINT/SIGTERM 共用一次清理；重复退出不会绕过等待。销毁渲染窗口停止全部客户端连接、上传与重连计时器，取消主进程下载，同时停止中转站与发现广播。
- 主进程下载与服务端流完成收尾后关闭数据库；退出期间拒绝新请求。超过5秒记录超时并强制退出，避免挂住。
- 渲染进程崩溃触发同一退出流程，避免主进程继续静默提供中转站服务。
- 新客户端每15秒发送应用层心跳；45秒没有有效状态或应答就主动重建连接，旧连接事件不能污染新连接。旧中转站回退到原有信息接口检测；主动断开与撤销凭证不会重新连接。
- 退出保留配对凭证和自动连接偏好，重启恢复客户端连接；本机中转站保持关闭，由用户开启。
- 主进程强杀、原生崩溃不能运行清理代码，监听由系统回收，远端通过连接断开或心跳判定离线；原有启动恢复逻辑修复设备和未完成任务。
