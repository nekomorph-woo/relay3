## 验收方式

- 主 Agent 自检，无独立视觉评审、不打分。
- 使用隔离预览数据，未修改用户正式文件或数据库。
- 类型检查与前端构建通过。
- 最终 13 项应用/滚动界面回归通过；多站回归另 1 项通过。
- 验证桌面 1404×942、1220×840、1080×720、800×600 和手机 320/375/414/768px 的相关界面。
- 回归包括双向文件收发、缓存/接收文件独立清理、跨站筛选、路径复制、设备提示、滚动位置、弹窗焦点恢复、密文与清理分页。
- 新增关键行为断言：删除按钮右侧间距、文件状态位于右侧、完整路径提示、中转站信息不随设备列表滚动、成功提示不覆盖保存按钮。
- 只做布局与提示样式调整，没有删除界面文案。
- Windows 未进行现场视觉验收；使用原生滚动条与稳定预留空间兼容 Windows 常驻式滚动条。
