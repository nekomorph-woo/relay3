# 原生滚动体验验收

日期：2026-10-05。使用当前 0.3.8 开发构建，不升级版本，不发布安装包。

## 实现结果

- 桌面保持固定工作台外壳，传输、待发送文件、设备、连接时间线、收发记录、文件存储、中转站连接各有独立列表滚动区。
- 文件发送、列表标题与筛选、设置保存、弹窗标题和底部操作不随正文滚动。存储路径三卡片放入独立弹窗，避免压缩文件列表。
- 普通弹窗、大厅信息、密文汇总、密文输入及历史清理统一正文滚动。清理消息提供摘要／展开全文，不再给每条消息增加滚动框。
- 设备选择使用原生顶层 popover，避免被面板或弹窗裁切；支持方向键定位选项、Esc 关闭并返回焦点。关闭弹窗也恢复触发控件焦点。
- 列表位置按页面、中转站和筛选范围隔离，使用行锚点与偏移恢复；筛选、分页回到起点。普通列表位置只存在当前进程内存，最多 200 项，不写入业务数据库。
- 群聊更早页定位页尾、较新页定位页首；回最新继续跟随。历史阅读与切页保留位置，新消息不抢位置；修复连续消息触发自动定位后误停跟随的问题。
- 手机窄屏文件传输降为自然页面滚动，设置内容可自然展开。群聊保持消息区与输入操作分离。
- 保留 Chromium 平台默认滚动条，不自绘、不强制隐藏、不接管滚轮和触控惯性。

## 验证

构建及变更文件格式检查通过；27 项服务／数据测试、22 项界面验收全部通过。

新增 5 项滚动验收覆盖：

1. 70 行设备、连接历史、缓存和接收文件；切页恢复、定时刷新不跳动、筛选与分页回顶。
2. 800×600 窗口、40 项待发送文件：发送和保存固定；路径弹窗正文滚动；复制完整路径及 Esc 焦点恢复。
3. 连续 65 条长消息、22 条长密文：历史定位、新消息不抢位置、密文分页回顶；70 个下拉选项键盘定位可见；长清理正文及密文输入底部操作固定。
4. 手机浏览器 320×640、375×812、414×896、768×1024：页面无横向溢出，设置保存和大厅信息弹窗可操作。
5. 两个中转站各有长传输列表：切站恢复各自位置；连接弹窗固定提交按钮。

既有验收同时覆盖双向文件传输、多站后台传输和消息隔离、密文授权、设备身份重置、重连、自动发现、诊断导出及异常采集。

桌面实际截图检查包括默认 1404×942 与最小 800×600；既有布局回归还覆盖 1220×840、1080×720。

## 验收范围

本机 Mac 上使用真实 Electron 窗口和 Chromium 手机浏览器上下文验收，测试数据均隔离。Windows 实机滚轮、系统常显滚动条偏好及真实手机触摸手感尚未现场验证。
