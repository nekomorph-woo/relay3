# 桌面多中转站连接

Windows / Mac Electron 客户端可以同时连接多个中转站。手机网页保持单站使用，本机服务端仍只运行一个中转站。

## 使用方式

- 侧栏选择当前查看的中转站，可从附近中转站发现、历史地址或配对链接添加连接。
- 文件传输与群聊大厅跟随选中的站。切换页面或站点不停止其他站的连接和传输；不同站的接收设备、待发送文件、聊天草稿、阅读位置与密文范围独立。
- “连接的中转站”集中展示连接状态、传输数量与未读消息，支持查看、断开、重新配对和忘记配对。
- 断开有未完成传输的站时先确认取消该站传输。忘记配对清除该站凭证，保留历史与已接收文件。
- 重启恢复上次保持连接的站与选中页面；手动断开的站不会自动连接。
- “本机中转站”和“连接设备”始终管理本机服务，关闭本机服务不会断开其他站。
- “收发记录”汇总各站传输并显示发生时的中转站名称，可按站筛选。
- “本机存储”展示本机中转缓存和已接收文件，已接收文件可按来源站筛选。

## 兼容与隔离

不回填历史记录，不依据设备、地址或当前连接猜测旧来源。缺少来源名称的旧记录和文件显示为“其他”，提供对应筛选。新增字段写入现有 SQLite JSON 数据，不增加历史表列，也不批量修改旧数据。

连接以 stationId 区分；传输进度、下载取消、临时文件和本机历史以站与传输 ID 共同隔离。同一站更换地址后保存最新凭证地址，旧记录的来源快照保持原样。不同站同名设备或相同传输 ID 不会合并。

各站独立维护 WebSocket 与退避重连。凭证失效、管理员断开或其他窗口接管后停止自动重试，由用户显式重新连接；断开单站不影响其他站。更换本机设备身份仍属于整个终端的操作，会断开全部站。

## 验收记录

验证环境：2026-10-05，Apple Silicon Mac，Electron 开发构建，隔离测试数据库与目录。

- 类型检查、生产构建及本次修改文件的格式检查通过。27 项服务测试、17 项 Electron / 网页界面测试全部通过。
- 服务测试覆盖保存连接意图与页面、忘记配对、同站更换地址、来源名称快照、跨站相同 ID、不回填旧 JSON 和“其他”筛选。
- 双站 Electron 测试覆盖并行连接、后台上传、同 ID 并行下载、指定站取消下载、群聊未读与草稿隔离、端侧密文隔离、记录/文件来源筛选、单站掉线恢复和重启恢复。
- 回归覆盖手机单站收发及响应式、桌面双角色、设备身份、平台标签、群聊、自动发现、重连与异常诊断。
- 验证 800×600 小窗口的侧栏底部入口可见、无横向溢出，桌面和手机原有布局回归通过。
- 界面截图：`design/qa/multistation-*.png`。

本机代理会拦截 Node 调试连接，测试使用临时 Unix socket 回环桥；没有修改用户代理设置。Windows 实机与跨物理设备的双站验收仍需用户体验确认。实现验收阶段没有打包或发布；随后用户授权 v0.3.8 发布，安装包核验记录见 `docs/verification.md`。
