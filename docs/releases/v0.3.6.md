# Relay3 v0.3.6

新增全局应用异常诊断，方便排查偶发闪退和操作失败。

- 使用 electron-log 统一记录主进程、页面与 React 异常、未处理 Promise 拒绝、接口和 IPC 失败、文件操作与实时连接异常。
- 增加本地原生崩溃转储和上次非正常退出检测，记录应用版本、系统信息、错误堆栈及操作阶段。
- 设置页新增诊断日志入口，支持复制路径、打开目录、导出 ZIP 和确认后清理。
- 手机网页已连接时的异常可记录在中转站。日志轮转和上报限速控制占用。
- 日志只在本地保存，不自动上传；普通日志中的配对凭证与密钥脱敏。导出不包含数据库、聊天密钥和传输文件。原生转储可能包含进程内存，请仅提供给信任的排查人员。

本版本先完善数据采集，Windows 缓存位置保存闪退将在取得诊断数据后继续排查。

提供 Mac Apple Silicon 与 Windows x64 安装包，沿用原数据目录。安装包未配置商业签名或 Apple 公证。
