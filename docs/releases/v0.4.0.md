Relay3 v0.4.0 将单文件和多文件统一为一次发送记录，支持完整上传后统一投递、失败项恢复、按需接收与包级管理，并整合设备身份和设置入口。

### 文件发送与接收

- 每次发送最多选择 100 个文件；单文件展示文件名，多文件展示「首个文件名 等 N 个文件」，无需生成 ZIP。
- 所有保留文件上传成功后才向接收者开放。失败项可单独重传，或移除后发送其余成功文件；发送完成后内容与接收名单固定，支持取消整次发送。
- 多个接收设备独立处理，可按需接收单个文件，或跨页选择多个文件批量接收。
- 同次发送的文件以最后一个上传成功的文件为基准，共用接收与缓存期限；重试发布、重新下载不延长期限。
- 发送者可按文件或设备查看接收进度、最近下载时间与传输耗时，并提醒在线未处理设备。
- 中转缓存按发送记录分组，支持展开、定位、整组选中和确认清理；保留旧版记录及旧中转站兼容。

### 群聊与加密文件名

- 一次文件发送在大厅中展示为一条记录，点击查看文件明细并处理接收。
- 群聊文件名仍在发送端逐个加密，绑定文件与发送记录；仅授权设备本地解密，文件内容本体不加密。
- 无权限文件名使用与密文消息相同的 100 条趣味句子随机占位，当前页面保持一致，重新加载后重新随机；公开备注仍可见。
- 接收端仅获取自己的接收任务和密钥信封，未授权设备不能查看文件明细或下载。

### 设备身份与设置

- 点击左上角头像管理设备名称、头像、身份 ID 复制和身份更换；头像随设备名称重新生成，无需保存图片。
- 连接弹窗的设备名称只读，连接不同中转站统一使用已保存的设备身份；更名后同步在线中转站，重连时更新旧名称。
- 删除桌面「本机管理／设备」页面，中转站名称、端口与保留时长移至「本机中转站」；存储位置设置保留在「接收文件」和「中转缓存」。
- 左下角新增 ScanEye 诊断日志入口，直接展示路径、占用及打开、导出、清理操作。
- 统一文本输入控件左右留白；设备身份与诊断弹窗仅通过右上角 X 关闭。

### 中转站生命周期

- 侧栏展示本机中转站状态及开启、关闭过程。
- 正常退出、窗口关闭和渲染进程崩溃时统一停止连接、传输及中转站，避免应用退出后服务静默运行。

### 安装与升级

- **Mac Apple Silicon**：`Relay3-0.4.0-mac-arm64.dmg`
- **Windows x64**：`Relay3-0.4.0-win-x64.exe`

退出旧版后覆盖安装，沿用原数据目录。旧记录保留原有展示；新增文件包数据表会在首次启动时创建。Mac 安装包使用本地签名，未进行 Apple 公证；Windows 安装包未使用商业代码签名。

暂不支持断点续传。手机浏览器收到文件后仍需确认收到。Windows 和 iOS Safari 未进行本轮实机验收，手机界面通过 Chromium 移动视口验证。

### 验证

- TypeScript 与生产构建通过，49 项服务测试和 37 项完整界面测试通过。
- 打包后的 Mac 应用通过桌面开启中转站、手机客户端连接、双向文件传输与历史保留验收。
- Mac 安装包通过签名校验，两个客户端分别确认为 arm64 与 Windows x64 架构。
