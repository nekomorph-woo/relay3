# relay3 v0.3.3

调整 Mac 与 Windows 桌面图标比例，保留原 r3 标志，采用带透明外边距的圆角底板，解决原白色背景铺满画布导致图标偏大的问题。

- Mac Dock、应用包图标和关于面板使用新的桌面图标。
- Windows 窗口、任务栏、程序 EXE 和安装程序 ICO 同步调整，包含 16、32、64、128、256 像素图层。
- 图标主体占画布宽度约 81%，参考 Electron 默认图标的视觉大小。
- 打包时先生成图标再编译，确保安装包资源一致。

提供 Mac Apple Silicon（macOS 13+）和 Windows x64（Windows 10+）安装包。退出旧版后覆盖安装，保留应用数据目录即可保留设置、配对和收发记录。

验证：TypeScript 检查与生产构建通过；两端安装包的运行时图标一致；Windows 程序与安装程序的 5 个图标图层已核对；Mac 应用递归严格签名验证通过。Windows 任务栏显示尚未实机验证。

Mac 使用 ad-hoc 签名，尚未 Apple 公证，首次打开可能需在系统隐私与安全性设置允许。
