# Relay3 v0.3.5（待确认发布）

本次完善中转站命名、历史连接探测和桌面侧栏。

- 设置页新增独立的中转站名称，与端口一起保存到本机 SQLite 设置；升级沿用原设备名称作为初始站名，之后修改设备名称不会改变站名。
- 中转站页、地址选项、群聊信息和历史连接列表展示站名，运行中也可修改，已连接客户端会收到更新。
- 打开连接弹窗时自动探测历史中转站，支持手动刷新，展示当前名称、地址、可连接状态和在线设备数。探测不会发送配对凭证，不会加入中转站。未响应可能由中转站关闭、地址变化或网络不可达造成；旧版不提供在线数时明确说明。
- 同一地址若已换成另一台中转站，提示重新配对，避免使用原凭证自动连接。
- 侧栏顶部改为本机头像与接入名称，移除品牌 Logo 区；底部保留版本，增加系统标准“关于”和默认浏览器打开 GitHub 的入口。

提供 Mac Apple Silicon 与 Windows x64 安装包。保留原有数据目录，覆盖升级可保留身份、设置、聊天密钥和历史。没有配置商业代码签名或 Apple 公证。Windows 和真实手机浏览器仍需实机验证。
