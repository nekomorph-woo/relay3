Relay3 v0.4.1 改善连接排障、大文件与文件夹发送、多站待办和后台中转，并增加头像外观刷新及更紧凑的中转站页面。

### 连接与多站待办

- 连接弹窗新增「检查连接」，分阶段检查地址、网络连接、中转站响应与身份，提供针对代理、防火墙、地址和配对凭证问题的排查建议，支持复制检查报告。
- 配对成功后等待中转站实际握手，避免界面误报已连接；握手超时与连接失联会提示。
- 全站待办集中查看不同中转站的未读消息与待接收文件，点击跳转对应中转站；桌面通知支持按站静音，初次连接不弹出历史通知。

### 文件传输

- 发送时展示准备、校验与上传阶段，以及上传速度和预计剩余时间，减少大文件发送时的等待不确定感。
- 中转站和接收目录增加可用空间检查，并计入并发任务已预留的容量。
- Windows／Mac 可选择整个文件夹，自动生成 ZIP 后发送，保留目录层级、中文名称和空目录；接收后由用户自行解压。
- 临近接收截止时间提醒在线未处理设备与发送者，提醒不延长原任务期限。
- 支持从原记录发起新的发送草稿，保留接收名单和公开备注；源文件缺失时重新选择。
- 重启后清理无法续传的上传半成品，保留任务历史并恢复容量预算。

### 群聊搜索

- 历史搜索由中转站执行，支持查找普通消息和公开备注，并跳转到对应消息。
- 密文正文和加密文件名不参与服务端明文搜索；短关键词在最近一万条消息中查找。

### 后台运行

- 可选择关闭窗口后继续运行，通过托盘／菜单栏管理中转站。
- 可分别开启传输期间、中转站运行期间防止自动休眠，屏幕仍可正常熄灭。
- 修复 macOS 后台隐藏窗口后点击 Dock 无法恢复的问题；恢复原窗口，保留已有连接。

### 头像与中转站界面

- 设备身份弹窗的头像右下角新增无边框刷新按钮，支持 Avatarka 八种主题与六种配色；按设备名称生成并保存外观，身份 ID 与配对保持不变。
- 头像外观同步到已连接中转站，在设备与群聊中统一展示；SVG 仅在内存中生成，不保存图片。
- 本机中转站设置集中到弹窗，本页保留设置入口，弹窗仅通过右上角 X 关闭。
- 设置下方新增在线设备头像宫格，悬停显示设备名称与本次连接时间；随窗口调整列数和行数，设备较多时分页。
- 调整中转站左右分栏与小窗口间距，减少页面滚动。
- README 更新设备身份、本机中转站设置与诊断入口介绍。

### 安装与升级

- **Mac Apple Silicon**：`Relay3-0.4.1-mac-arm64.dmg`
- **Windows x64**：`Relay3-0.4.1-win-x64.exe`

退出旧版后覆盖安装，原设备身份、配对、历史记录与存储设置保留。

Mac 安装包使用本地签名，未进行 Apple 公证；Windows 安装包未使用商业代码签名。暂不支持断点续传；防自动休眠不保证阻止手动睡眠或笔记本合盖休眠。文件夹 ZIP 外部名称沿用原权限规则，压缩包内的文件内容和目录名称不加密。
