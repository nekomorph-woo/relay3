# Relay3 v0.3.4

新增局域网群聊大厅，连接同一中转站的电脑和手机可以交流文字。消息在中转站 SQLite 中永久保存，由管理员手动清理。

- 参考即时通信应用布局：消息流、底部输入区、右侧中转站和在线/离线设备栏；手机通过抽屉查看信息，设备列表每 30 秒更新。
- 纯文本、Markdown、HTML 均按原文展示，提供发送者、时间和一键复制，不渲染 HTML。正文最多 10000 个字符，不支持图片、文件或撤回。
- 默认普通模式；密文发送使用独立弹窗，正文与普通草稿分开。可选择在线设备或已登记公钥的离线设备，发送者固定包含。
- 正文在发送端通过 X25519、HKDF-SHA256 和 AES-256-GCM 加密，在指定设备本地解密；中转站保存密文。有权限显示开锁图标，无权限显示锁图标与趣味句子，仍可复制实际密文。
- 密文支持公开备注，提供提示、说明、线索样式，所有设备都可查看和复制。
- 每个设备保存阅读位置，支持未读计数、跳转上次未读、历史分页，以及每页 20 条的密文汇总弹窗。
- 管理员可同时组合时间、发送设备、消息模式与勾选消息进行清理；预览后确认，保护预览之后的新消息，保留文件记录和磁盘文件。
- 修复本机加入后再次加入失败，桌面重连凭证在 SQLite 中持久保存，支持跨重启连接本机或远端中转站；重连优先使用原凭证。
- 引入 avatarka 统一设备头像，使用设备 ID 固定生成；消息、设备列表、密文接收名单与本机身份保持一致。SVG 仅在内存中生成，不保存图片文件。
- 存储位置采用三个独立卡片，展示用途说明与完整路径，支持一键复制；单个操作按钮铺满，多个按钮等分宽度。
- 调整配对区域宽度与按钮布局、密文备注对齐和大厅输入间距；设备展示登录次数、连接时间线标记本机，设置页上方集中身份信息并支持复制设备标识符。
- 统一品牌显示为 Relay3，沿用旧版数据目录，保留设置、身份、私钥与记录。
- 移除顶部连接状态栏和大块连接引导；文件传输以当前传输为主，连接与管理按钮集中在页头。设备、记录和存储列表各自滚动，路径与数据库整理收进可展开区域，手机采用自然堆叠布局。
- 移除自定义桌面菜单，保留复制、粘贴、剪切、全选、撤销等快捷键。

提供 Mac Apple Silicon（macOS 13+）和 Windows x64（Windows 10+）安装包。退出旧版后覆盖安装，保留应用数据目录即可保留设置、配对和收发历史。

密文私钥只保存在终端。更换身份或清空浏览器数据后，无法读取旧身份密文；公开备注始终可见。请在可信局域网与可信中转站中使用。

安装包没有配置商业代码签名；Mac 使用 ad-hoc 签名，尚未 Apple 公证。Windows 与真实 iOS/Android 浏览器的运行行为仍需实机验证。
