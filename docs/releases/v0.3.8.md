# Relay3 v0.3.8

Windows / Mac 客户端现在支持自动发现局域网中转站，并同时连接多个中转站。

## 发现与连接

- 连接窗口展示附近已开启的中转站，选择后输入一次性配对码即可加入；保留手动地址、配对链接与历史连接方式。
- 按中转站身份验证并合并发现结果；已配对的站更换地址后可复用连接凭证。
- 新增“连接的中转站”管理页面，展示各站状态、传输数量与未读消息，支持切换、单独断开和忘记配对。
- 重启恢复上次保持连接的站和选中页面；单站掉线独立重连，不影响其他连接。管理员断开后可显式重新连接。

## 多站传输与群聊

- 文件传输、接收设备与群聊大厅跟随当前选中的站；切换后其他站的传输继续运行。
- 各站聊天草稿、阅读位置、未读消息与密文范围独立，避免跨站混用。
- 收发记录汇总各站文件并保留中转站名称快照，支持按站筛选。
- “文件存储”更名为“本机存储”，已接收文件展示来源站并支持筛选。
- “本机中转站”与“连接设备”始终管理本机服务；本机仍只开启一个中转站。

## 兼容与界面

- 手机浏览器保持单站使用，继续支持扫码连接。
- 不回填旧记录的中转站来源，缺少来源的记录和文件显示“其他”，可单独筛选。
- 默认桌面窗口调整为 1404 × 942，并优化 800 × 600 小窗口的侧栏布局。
- 覆盖升级沿用原数据目录，保留身份、设置、历史和已接收文件。

提供 **Mac Apple Silicon** 与 **Windows x64** 两种安装包。自动发现需要局域网允许 mDNS 广播；未发现时仍可手动连接。

类型检查、生产构建、27 项服务测试及 17 项界面测试通过。Windows 实机和跨物理设备多站行为仍需实际使用验证。安装包未配置商业签名或 Apple 公证。
