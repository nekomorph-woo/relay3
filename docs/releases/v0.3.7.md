# Relay3 v0.3.7

修复 Windows 缓存目录迁移的原生复制崩溃问题，并调整群聊备注展示。

- 缓存目录迁移改为异步逐项复制，绕开 Node `cpSync` 原生目录复制路径中可能导致进程退出的文件系统异常。
- 复制或设置保存失败时回滚目标复制项，保留原缓存和原设置；迁移期间阻止开启中转站、缓存清理及并发保存，退出时等待迁移结束。
- 旧缓存目录清理失败时明确提示，不把已保存的新设置当成迁移失败。
- 群聊备注移到正文上方，以 Markdown 引用式左竖线和缩进展示。格式为“提示/说明/线索：备注内容”，标签加粗，标签与内容同字号，保留复制入口。大厅与密文汇总统一样式。

提供 Mac Apple Silicon 与 Windows x64 安装包，沿用原数据目录，覆盖升级保留身份、设置与历史。

缓存迁移修复已通过自动化验证；用户提供日志中的 Windows 环境仍需安装本版复测。安装包未配置商业签名或 Apple 公证。
