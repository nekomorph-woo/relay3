# 文件包实现与验收

Goal：新增 FilePackage，统一单/多文件原子成包、共同期限、部分接收与群聊交互，兼容旧记录。

- [ ] T1 包模型、关联表、事务创建/发布、统一D/T、失败重传/移除、整包取消
- [ ] T2 权限、群聊一次消息及文件名加密、提醒、包级清理与旧协议兼容
- [ ] T3 客户端成包流程、失败恢复、文件包展开与批量接收队列
- [ ] T4 发送/接收记录、缓存管理、群聊弹窗、跨站与本地历史
- [ ] T5 服务边界测试、Electron/手机验收、生产构建与阶段提交

## 已确认规则

- 单文件与多文件统一文件包。同一个包的文件与接收名单固定。
- 上传成功文件先暂存，全部成功才成包；失败时支持重传原文件或移除失败/未上传文件后保留成功文件。成包前对接收者不可用。
- 成包的共同基准为保留文件中最后一个上传成功的时间。每个文件写入相同D/T，不通过读取包期限代替文件记录。
- 成包后不能追加、改名单或移除成员；发送者可取消整个包。已收到的本地文件和历史不删除。
- 接收者选择部分或全部文件。排队未开始下载的文件跨D后不可首次下载；进行中继续完成。
- 手动提醒在线未处理设备，包/设备60秒冷却，D前有效，不积压离线提醒。
- 未授权群聊设备只看发送者、时间、公开备注和通用文件包；不暴露数量、大小、名单、文件密文。
- 包级缓存清理跳过正在传输文件并返回结果，历史保留。
- 旧记录不回填；新结构追加。未完成上传保留24小时恢复窗口；不支持断点续传。
- UI中文“文件包”，代码FilePackage；批量下载逐文件保存，不生成ZIP。
- 本轮不升版本、不推送、不打tag、不发布。
